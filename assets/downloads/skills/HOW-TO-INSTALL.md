# Marketing Skills Pack — How to install and use

These skills come from the *Get Smarter with Your Marketing* workshop (AIM AI
Bootcamp for Small Business, City of Sydney). Each one turns something you did
in the session into a tool you can reuse any time.

## What's in each skill

Every skill comes in two formats — pick the one that matches the AI tool you
use:

- **`<skill-name>.skill`** — for Claude. A small package Claude can install so
  the skill runs automatically when you ask for it.
- **`prompt-version.txt`** — for ChatGPT (or any other AI tool). The same
  skill condensed into a single prompt you copy and paste into a new chat. No
  installation needed.

## Installing in Claude

1. Open Claude (claude.ai) and start a new chat.
2. Attach the `.skill` file to your message and ask Claude to save it as a
   skill — or, in Settings, look for **Skills** and upload it there if your
   plan shows that option.
3. That's it. Next time you ask for the thing the skill does ("set up my brand
   voice"), Claude uses it automatically.

If your Claude plan doesn't support installing skills, no problem — use the
`prompt-version.txt` exactly as you would in ChatGPT. Same result.

## Using in ChatGPT (or anything else)

1. Open the skill's `prompt-version.txt`.
2. Copy everything below the dividing line.
3. Paste it into a new chat and follow along. The AI will ask you questions
   one at a time.

## Start in this order

The first two skills create things every other skill uses. Do them first —
about five minutes each:

1. **sound-like-us** — builds your *brand voice block*: how your business
   sounds.
2. **customer-persona** — builds your *customer persona*: who you're talking
   to.

Save both results somewhere handy (a note on your phone is fine). When you use
any other skill in this pack, paste them in at the start of the chat — that's
what keeps AI content sounding like you, written for your actual customer,
instead of generic AI slop.

## One safety habit

Before pasting anything into any AI tool, check it for real customer names,
contact details, staff information, or private money figures — and take them
out. The `before-you-paste` skill in this pack does this for you.
